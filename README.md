# Vault bot

Телеграм-бот: кидаешь ему медиа, он прячет в разделы Видео / Кружки / Сливы.
Все твои сообщения и сообщения бота удаляются, в чате остаётся только одна панель.

## Запуск (всё с телефона)

1. **Supabase**: создай проект, открой SQL Editor, вставь `schema.sql`, Run.
   В Settings → API возьми `Project URL` и ключ `service_role`.
2. **GitHub**: создай репозиторий (лучше приватный), загрузи `bot.py` и `requirements.txt`.
3. **Render**: New → Web Service → подключи репозиторий.
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python bot.py`
   - Instance type: Free
4. В Environment добавь переменные:

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `ADMIN_ID` | твой Telegram ID (узнать у @userinfobot) |
| `PASSWORD` | пароль для остальных пользователей |
| `SUPABASE_URL` | Project URL |
| `SUPABASE_KEY` | ключ service_role |

5. Чтобы бесплатный Render не засыпал, зайди на https://uptimerobot.com и добавь HTTP-монитор
   на адрес твоего сервиса (интервал 5 минут). Бот ещё и сам пингует себя раз в 10 минут.

## Как пользоваться

- `/start` открывает панель.
- Кинь видео → раздел Видео. Кружок → Кружки. Фото, гифки, файлы → Сливы.
- Кнопка «📥 Режим загрузки» переключает: авто или всё в Сливы.
- Нажми на раздел, бот покажет 5 последних, у каждого кнопка 🗑 для удаления. ⬅️ ➡️ листают.
- Ты админ: пароль не нужен, есть `/stats`. Остальные вводят пароль и каждый час вводят заново.
- Файлы хранятся у Telegram (бот сохраняет только file_id), так что место не занимают.
